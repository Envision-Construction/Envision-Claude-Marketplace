## Typography

**Helvetica Neue** — the only typeface. No exceptions.

| # | Weight  | Usage |
|---|---------|-------|
| 1 | **Thin** | Large display type, cover subtitles, supporting copy at scale |
| 2 | **Regular** | Body text, bullet items, descriptions, captions |
| 3 | **Medium** | Sub-labels, table headers, metadata labels, team titles, process headings |
| 4 | **Bold** | Cover wordmarks, proposal title cards, key callouts, small bold labels |

**Key principle**: Large section titles use **Thin or Regular** weight at large scale (40–70pt) for an airy, premium feel. Bold is reserved for cover wordmarks and small high-emphasis labels — not large display headlines.

**Web/CSS fallback stack**: `"Helvetica Neue", Helvetica, Arial, sans-serif`

**ReportLab font names** (system Helvetica Neue):
- `Helvetica` (Regular)
- `Helvetica-Bold` (Bold)
- `Helvetica-Oblique` (Italic)

> Note: Helvetica Neue is a licensed typeface. For web use, Neue Haas Grotesk (Adobe Fonts) or Inter (Google Fonts) are the closest free alternatives. Never substitute Montserrat.

## Document Design System

### Page Layout Standards

| Document Type     | Background       | Header                        | Footer            |
|-------------------|------------------|-------------------------------|-------------------|
| **SOQ**           | `#F5F5F5` warm gray | Green thin bar full width (~4px) | Section label left, cornerstone icon right |
| **Proposal**      | White `#FFFFFF`  | Green thin bar full width     | "ENVSN.COM" centered, Green |
| **Cover pages**   | Full-bleed photography with dark overlay | — | "ENVSN.COM" centered, White |
| **Divider pages** | Full-bleed photography with dark overlay | — | Cornerstone icon bottom-right, White |

- **Page size**: Letter (8.5×11in) for standard; 11×17in landscape for SOV pages in proposals
- **Content margins**: Minimum 0.55in on all sides
- **Header bar**: Thin green (`#007A53`) ~0.055–0.07in full-width bar at very top of every page

### 11×17 Proposal Page System (ReportLab)

**Page size**: 17 × 11 inches (`PAGE_W = 17 * inch`, `PAGE_H = 11 * inch`)

**Header**:
- Thin green bar (`#007A53`, ~0.07in) full width at very top
- Page number bold + `"- SECTION TITLE"` regular, 9pt Black, left margin
- Logomark PNG top right, ~0.28in tall

**Footer — four left-anchored items at fixed x positions (do NOT center)**:
1. `"ENVISION"` — Helvetica-Bold 9pt, Black, at `MARGIN_L`
2. Project name — Helvetica 9pt, Grey `#929296`, at `MARGIN_L + 1.40in`
3. Project number — Helvetica 9pt, Grey, at `MARGIN_L + 3.80in`
4. `"ENVSN.COM"` — Helvetica-Bold 9pt, Green `#007A53`, hard right at `w - MARGIN_R`

**8.5×11 Portrait Page System**:
- Same header/footer chrome as above
- Footer project name at `MARGIN_L + 1.10in`, project number at `MARGIN_L + 3.40in`

### Core Design Motifs

**Vertical accent bar**: 4–5px Green (`#007A53`) bar running full height of multi-line section titles.

**Dark photography overlays**: Cover and divider pages use very dark overlays (~85–90% opacity, green tint). Never 70% — too transparent.

**Light Green accent borders**: Thin Light Green (`#CAE8E0`) border on the left edge of right-side photography in split-layout pages.
