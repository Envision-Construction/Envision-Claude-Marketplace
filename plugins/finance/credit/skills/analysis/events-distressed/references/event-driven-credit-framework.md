# Event-Driven Credit Framework

Use this reference when a transaction, financing, ownership change, or governance event can materially change downside, repayment capacity, or creditor priority. The goal is not to predict headlines; it is to determine how the event changes the creditor's position if it closes, slips, or fails.

## 1. Start with the Event Itself

Classify the event before analyzing it:

- **Issuer-led event**: acquisition, asset sale, refinancing, exchange, recapitalization
- **Owner-led event**: sale process, IPO, dividend recap, sponsor transfer, governance reset
- **Process event**: waiver, amendment, tender, consent solicitation, default notice
- **Control event**: change of control, merger, board turnover, management replacement

For every event, answer four opening questions:

1. What changes economically if the event closes?
2. What changes legally or structurally if the event closes?
3. What happens if the event is delayed or fails?
4. Who benefits most: the company, equity, new money, or existing creditors?

## 2. Core Event Analysis Template

### Deal / Event Risk

- Identify the approvals, financing commitments, lender consents, and regulatory steps required
- Distinguish signed, financed, and closed; those are different levels of certainty
- Test the fallback case explicitly rather than assuming the announced path succeeds

### Pro Forma Credit Effect

- Rebuild leverage, coverage, liquidity, and maturity profile on a post-event basis
- Separate hard changes from management aspirations such as synergies or growth targets
- Test whether the event improves runway or merely postpones the problem

### Structural Effect

- Map whether the event adds debt at OpCo, HoldCo, unrestricted subsidiary, or special-purpose entity level
- Identify whether existing claims are assumed, refinanced, retired, primed, or left behind
- Review guarantees, collateral migration, and any change in the cash-flow path to creditors

### Documentation Effect

- Check change-of-control puts, debt incurrence baskets, restricted payments capacity, and lien provisions
- Confirm whether the event requires creditor consent or can be executed under existing flexibility
- Distinguish formal covenant protection from practical negotiating leverage

### Investor Conclusion

- Determine whether the event is credit-positive, credit-negative, or path-dependent
- State what the market price appears to assume
- Define what would make the position more attractive or force an exit

## 3. Common Event Types

### Issuer Announces an Acquisition

Focus on whether the issuer is buying growth with balance sheet capacity or borrowing future trouble.

- Rebuild the sources and uses and the post-close capital structure
- Haircut synergies and timing assumptions
- Test whether new debt sits beside, above, or outside existing creditors
- Compare the strategic logic with the financing burden; good strategy can still be bad credit

### Issuer Is Acquired / Change of Control

Focus on what happens to existing debt and how new ownership changes incentives.

- Determine whether debt is assumed, refinanced, put back, or left structurally worse
- Review change-of-control protections and the issuer's practical ability to honor them
- Distinguish a strategic buyer improving the credit from a sponsor buyer levering the asset
- Re-underwrite the business under the new owner's expected capital allocation behavior

### IPO or Other Equity-Raising Event

Treat equity access as a potential balance-sheet tool, not an automatic credit positive.

- Separate primary proceeds from secondary monetization
- Determine whether cash reaches the company or only existing owners
- Test whether proceeds actually delever or simply create more flexibility for future distributions
- Define the downside if the transaction is postponed and the owner pursues a different exit path

### Maturity / Refinancing Event

Focus on refinancing feasibility rather than on the maturity date alone.

- Compare the existing capital structure with the one the market is likely to fund
- Test interest burden, covenant headroom, and maturity runway after refinancing
- Identify springing maturities, near-term step-downs, and any need for layered financing
- Separate a liquidity bridge from a durable fix

### Management / Ownership Change

Treat management and owner incentives as credit variables when they can change leverage tolerance, asset sale behavior, or restructuring posture.

- Assess the new decision-maker's time horizon, risk appetite, and history with creditors
- Determine whether the change raises the odds of a sale, recap, amendment, or aggressive LME
- Reassess strategy credibility, capital allocation discipline, and willingness to preserve liquidity

## 4. Questions That Should Always Be Answered

- What is different for creditors if the event closes?
- What is different if the event fails?
- Does the event improve enterprise value, just reshuffle value, or extract value from existing creditors?
- Which class is helped, harmed, or newly subordinated?
- Is the announced transaction the real end state, or just an intermediate step toward a later restructuring?

## 5. Common Mistakes

- Treating announcement as completion
- Giving full credit to synergies, equity raises, or asset sale proceeds before the cash is real
- Ignoring where new debt sits in the legal structure
- Focusing on headline leverage while missing covenant or priority deterioration
- Analyzing the closing case without underwriting the broken-deal case
