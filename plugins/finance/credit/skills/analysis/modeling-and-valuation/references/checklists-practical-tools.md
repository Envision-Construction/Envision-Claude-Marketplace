## Checklists & Practical Tools

### Comparable Companies Analysis Checklist

- [ ] 8–15 comparable companies identified and justified
- [ ] Stock prices, shares outstanding, dilution calculated
- [ ] Total debt, cash, preferred stock, MI identified
- [ ] LTM and NTM EBITDA, revenue, EBIT sourced
- [ ] EV calculated for each comp
- [ ] EV/EBITDA, EV/Revenue, P/E calculated
- [ ] Mean, median, high, low, Q1, Q3 computed
- [ ] "Closest comps" narrowed and justified
- [ ] Valuation range applied to target
- [ ] Any multiples outliers investigated and explained
- [ ] Cross-check: Do other methodologies support valuation range?

### DCF Model Checklist

- [ ] 5–10 year revenue projection built (vs. historical trends, management guidance, market research)
- [ ] EBITDA margin normalized and projected (account for scale, competition, one-time items)
- [ ] D&A, CapEx, working capital normalized
- [ ] Tax rate set to marginal rate (not effective rate)
- [ ] WACC calculated with market-based inputs (current Rf, comparable beta, market ERP)
- [ ] Terminal value calculated two ways (exit multiple AND perpetuity growth); cross-checked
- [ ] Present values computed at correct discount rate
- [ ] Sensitivity tables built for WACC, terminal growth, revenue assumptions
- [ ] EV-to-equity bridge calculated (debt, cash, MI adjustments)
- [ ] Implied price per share reasonable relative to current market price
- [ ] DCF result compared to trading comps, precedent transactions

### LBO Model Checklist

- [ ] Entry price justified (entry multiple × EBITDA)
- [ ] Debt structure defined (TL-A, TL-B, Sr Notes, Sub Notes, Revolver)
- [ ] Total debt ÷ LTM EBITDA = 4.0x–5.0x (or justified otherwise)
- [ ] Sponsor equity calculated as "plug" (Total Uses - Debt - Rollover)
- [ ] Sources & Uses balanced
- [ ] 5-year operating model built (Revenue, EBITDA, D&A, Interest, Taxes)
- [ ] Debt schedule modeled for each tranche (opening bal, amortization, sweep, closing bal)
- [ ] Interest expense calculated correctly (SOFR-based rates, fixed coupons, PIK accruals)
- [ ] Free cash flow calculated (EBITDA - Cash Interest - Taxes - CapEx ± NWC)
- [ ] Debt paydown modeled per waterfall (mandatory amort → sweep → optional)
- [ ] Remaining debt at exit calculated
- [ ] Exit enterprise value set (Exit Multiple × Exit Year EBITDA)
- [ ] Exit equity value = Exit TEV - Remaining Debt
- [ ] IRR and MOIC calculated
- [ ] Sensitivity tables built (Entry vs. Exit Multiple; Leverage vs. IRR; Growth vs. IRR)
- [ ] Returns benchmarked vs. target (20%+ IRR, 2.0x+ MOIC)

### Football Field Summary Checklist

- [ ] All four methodologies presented side-by-side
- [ ] Valuation ranges clearly labeled (Low, Mid, High)
- [ ] Control premium explained vs. trading comps
- [ ] Fair value range identified and reconciled
- [ ] Recommended offer price highlighted (typically top end of trading comps, bottom end of precedent)
- [ ] Sensitivity to key assumptions called out
