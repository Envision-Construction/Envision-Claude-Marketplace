## Part 5: Accretion / Dilution Analysis

Used in strategic M&A (one public company acquiring another) to show impact on acquirer's earnings.

### Concept

```
Accretive = Combined Pro Forma EPS > Acquirer Standalone EPS
            (Deal increases acquirer's earnings per share)

Dilutive  = Combined Pro Forma EPS < Acquirer Standalone EPS
            (Deal decreases acquirer's earnings per share)
```

### Key Drivers

**Earnings Accretion / Dilution Formula:**

```
Year 1 Pro Forma EPS = (Acquirer NI + Target NI + Synergies) / Acquirer Pro Forma Diluted Shares

Vs.

Acquirer Standalone EPS = Acquirer NI / Acquirer Diluted Shares
```

**Primary Drivers:**

1. **Financing Mix:**
   - All-cash financed at high interest rates → Dilutive (interest expense reduces earnings)
   - Stock-financed → Dilutive (share count increases; need strong earnings accretion from target to offset)
   - Debt at low rates → Less dilutive (interest tax-deductible)

2. **P/E Arbitrage:**
   - Acquiring lower P/E target into higher P/E acquirer → Accretive
   - Acquiring higher P/E target into lower P/E acquirer → Dilutive

   Example:
   ```
   Acquirer: EPS $2.00, P/E 20x, Price $40
   Target: EPS $1.00, P/E 12x, Price $12

   If acquirer issues stock at $40 to buy target at $12:
   New shares issued = $12 / $40 = 0.30 shares per target share
   Target brings in $1.00 EPS but costs 0.30 shares → $1.00/0.30 = $3.33 EPS accretion

   But acquirer EPS = $2.00 spread over larger share count
   Accretive or dilutive depends on exact mix
   ```

3. **Synergies:**
   - Cost synergies (SG&A reduction, procurement, elimination of duplicates)
   - Revenue synergies (cross-selling, product bundling)
   - Tax benefits
   - Working capital improvements

   Synergies directly improve pro forma earnings.

4. **Financing Costs:**
   - Acquisition fees, financing fees reduce Year 1 earnings
   - Interest expense on debt (or foregone interest on cash) reduces earnings
   - Accretion / dilution calculations often exclude one-time deal fees to show "run-rate" impact

### Example Accretion / Dilution Calculation

```
Acquirer:
  Net Income: $500M
  Diluted Shares: 200M
  EPS: $2.50
  Stock Price: $50
  P/E: 20x

Target:
  Net Income: $100M
  Diluted Shares: 50M
  EPS: $2.00
  Valuation: $600M (12.0x P/E)

Deal Terms: Acquirer to issue stock at $50 to buy target for $600M

New Shares Issued = $600M / $50 = 12M shares

Pro Forma Standalone (no synergies):
  Combined NI: $500M + $100M = $600M
  Shares: 200M + 12M = 212M
  Pro Forma EPS: $600M / 212M = $2.83

  vs. Acquirer Standalone: $2.50

  Accretion: ($2.83 - $2.50) / $2.50 = 13.2% Accretive

With Synergies ($50M annual COGS savings):
  Combined NI: $600M + $50M = $650M (net of tax at 25%)

  Synergy value: $50M × (1 - 0.25) = $37.5M after-tax
  Pro Forma NI: $600M + $37.5M = $637.5M
  Pro Forma EPS: $637.5M / 212M = $3.01

  Accretion: ($3.01 - $2.50) / $2.50 = 20.4% Accretive
```

### Presentation

Accretion / dilution is typically shown in a table:

```
                    Year 1      Year 2      Year 3
────────────────────────────────────────────────────
Acquirer Standalone EPS    $2.50       $2.65       $2.80
Pro Forma (no synergies)   $2.83       $2.95       $3.10
Accretion (%)             13.2%       11.3%        10.7%

Pro Forma (with synergies) $3.01       $3.18       $3.35
Accretion (%)             20.4%       20.0%        19.6%
```
